# JavaScript Web Shooter
- This is the client side continuous assessment assigned in the second semester of 1st Year Computer Science. The task was to create a client side JavaScript web shooter.
- A playable version can be found here: https://js-web-game.onrender.com/
- Please allow for some time to visit the links as the server must begin running upon your request!
 
## How To Play

In this game you have been sentenced to death for being a wizard among the ordinary, and the whole village is after you! Luckily since you're a wizard you have means to deal with them! Your aim is to dispose of the villagers using your love for fireballs. Since you're magic it can be in any direction!

- Controls:

    - W S A D to move forwards, backwards, left and right respectively.
    - Left click where you want to shoot.
    - Press R to refill your mana.


If you figure out how to cheat, you will be punished with eternal gameplay as you cannot die! Say goodbye to that sweet leaderboard entry!

- Power-Ups
    - Heart - When picked up the player regains 30HP.
    - Surge - When picked up the player shoots fireballs in eight directions for 5s.
    - Speed Gem - When picked up the player's speed triples for 10s.
    - Shield - When picked up the player gets a shield which voids all damage for 10s.
    - Death Plate - When picked up the player instantly kills all other enemies, ending the round.
